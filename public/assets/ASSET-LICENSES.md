All visual assets currently shipped with the game are original project assets.

| Asset | Source | License / usage |
| --- | --- | --- |
| `models/palace-puppet.glb` | Generated from `scripts/generate-model-assets.mjs` in this repository | Original project asset; may be used with this project |

Any future third-party model, texture or audio must be added to this table with its author, source URL and license before release.
